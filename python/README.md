# Python — Labs & Scripts

Ce dossier regroupe mes **exercices Python**, **scripts**, **mini-projets** et **expérimentations** autour du langage Python.

Il sert de base pour :
- renforcer les fondamentaux du langage
- tester des concepts isolés
- conserver des scripts réutilisables
- illustrer des notions Python de manière concrète

Les projets présents ici sont principalement **pédagogiques** et **progressifs**.

## Contenu du dossier

```text
python/
├── scripts/        → scripts Python simples et utilitaires
├── beginner/       → bases du langage (variables, conditions, boucles…)
├── intermediate/   → concepts intermédiaires (fonctions, modules, OOP…)
├── algorithms/     → algorithmes et logique (tri, recherche, etc.)
└── README.md
```

Chaque projet est organisé de manière autonome, avec des fichiers et dossiers clairs, permettant de se concentrer sur des aspects spécifiques du langage.

## Contenu du dossier
- **Scripts** : petits scripts Python pour des tâches spécifiques (automatisation, manipulation de fichiers, etc.)
- **Beginner** : exercices et projets pour les débutants (variables, conditions, boucles, etc.)
- **Intermediate** : exercices et projets pour les utilisateurs intermédiaires (fonctions, modules, programmation orientée objet, etc.)
- **Algorithms** : exercices et projets liés aux algorithmes et à la logique de programmation (tri, recherche, etc.)
- **Expérimentations** : projets personnels, idées en cours de développement, prototypes, etc.
- **Documentation** : notes, guides, références pour les technologies utilisées dans les projets.
- **Bonnes pratiques** : exemples de bonnes pratiques de développement avec Python (structure, organisation du code, utilisation des modules, etc.)
