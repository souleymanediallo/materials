# Flask — Mini Apps & APIs

Ce dossier regroupe mes **mini-applications Flask**, **APIs simples** et **expérimentations** autour du framework Flask.

Flask est utilisé ici comme un outil léger pour :
- créer rapidement des applications web
- prototyper des APIs
- tester des idées ou des intégrations
- comparer différentes approches backend

Les projets présents dans ce dossier sont principalement **exploratoires** et **pédagogiques**.

## Organisation du dossier

```text
flask/
├── mini-apps/     → applications Flask simples
├── api/           → APIs REST légères
├── experiments/   → tests techniques, POC, essais
└── README.md
```

Chaque projet est organisé de manière autonome, avec sa propre structure Flask, permettant de se concentrer sur des aspects spécifiques du framework.

## Contenu du dossier
- **Mini-apps** : petites applications Flask illustrant des concepts de base (routes, templates, formulaires, etc.)
- **API** : exemples d’APIs RESTful simples avec Flask, utilisant Flask-RESTful ou Flask-API
- **Experiments** : projets personnels, idées en cours de développement, prototypes, etc.
- **Documentation** : notes, guides, références pour les technologies utilisées dans les projets.
- **Bonnes pratiques** : exemples de bonnes pratiques de développement avec Flask (structure, organisation du code, utilisation des extensions, etc.)
