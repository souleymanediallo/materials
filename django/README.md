# Django - Projets & Labs

Ce dossier regroupe mes **projets Django**, **mini-applications** et **expérimentations** autour du framework Django.

Il sert de laboratoire pour :
- pratiquer Django de manière concrète
- explorer les bonnes pratiques (structure, ORM, vues, templates)
- tester des fonctionnalités isolées
- préparer des projets plus avancés ou orientés production

Les projets présents ici sont principalement **pédagogiques** et **évolutifs**.

## Organisation du dossier

```text
django/
├── blog/            → blog Django (models, views, templates)
├── auth/            → authentification, permissions, users
├── crud/            → opérations CRUD classiques
├── api/             → Django REST Framework (APIs)
├── tests/           → tests unitaires et fonctionnels
└── README.md
```

Chaque projet est organisé de manière autonome, avec sa propre structure Django, permettant de se concentrer sur des aspects spécifiques du framework.

## Contenu du dossier
- **Blog** : projet de blog complet avec gestion des articles, catégories, commentaires, etc.
- **Auth** : projet d’authentification avec gestion des utilisateurs, permissions, groupes
- **CRUD** : mini-projet illustrant les opérations CRUD (Create, Read, Update, Delete)
- **API** : exemples d’APIs RESTful avec Django REST Framework
- **Tests** : exemples de tests unitaires et fonctionnels pour les projets
- **Expérimentations** : projets personnels, idées en cours de développement, prototypes, etc.
- **Documentation** : notes, guides, références pour les technologies utilisées dans les projets.
- **Bonnes pratiques** : exemples de bonnes pratiques de développement avec Django (structure, organisation du code, utilisation de l’ORM, etc.)
- **Déploiement** : exemples de configurations pour le déploiement des applications Django (Heroku, Docker, etc.)
- **Optimisation** : techniques d’optimisation des performances, mise en cache, requêtes efficaces, etc.
- **Sécurité** : bonnes pratiques de sécurité spécifiques à Django (protection CSRF, gestion des sessions, etc.)
- **Migrations** : gestion des migrations de base de données avec Django ORM.
